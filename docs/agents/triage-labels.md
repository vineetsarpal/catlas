# Triage labels

| Canonical role | Linear label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting for reporter information |
| ready-for-agent | ready-for-agent | Fully specified; agent can implement |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Use these label strings when a skill refers to a canonical role.
Labels describe triage readiness; Linear statuses track progress.
