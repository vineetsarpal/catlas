# Issue tracker: Linear

Issues and specs live in Linear team catlas (CAT).

- Team ID: 90118515-fd18-470f-9ae4-1b09285e6635
- New issues start in Backlog.
- No default project; leave project unset unless specified.
- Use the connected Linear tools for tracker operations.

## Conventions

- Create issues and specs in this team.
- Fetch issue details and comments before working on a ticket.
- Scope issue searches and listings to this team.
- Use Linear comments for progress, decisions, and results.
- Apply triage labels using `docs/agents/triage-labels.md`.
- Preserve existing labels when adding or removing triage labels.
- Use In Progress when implementation starts, In Review when ready
  for review, and Done when complete.
- Use Canceled for work that will not proceed and Duplicate for
  duplicate issues.
- Record blocking relationships and parent/sub-issue relationships
  in Linear.

“Publish to the issue tracker” means create a Linear issue.
“Fetch the relevant ticket” means read the Linear issue and comments.
